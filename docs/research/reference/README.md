# Design reference

These documents preserve the broad research model that preceded the current prototype. They are not
the current product contract.

Read the [`design plan`](../../design/PLAN.md) for current architecture and version boundaries.

- [`capture.md`](capture.md) covers compiler and Cargo behavior.
- [`implementation.md`](implementation.md) covers the data model and collection protocol.
- [`test-matrix.md`](test-matrix.md) covers the release contract tests.

Historical commands, measurements, and compiler observations remain useful evidence. Product plans,
schema descriptions, and status labels in this directory can be obsolete.
